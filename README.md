# 남미 여행 사진/영상 자동 지역 분류기 (Photo Classifier)

수천 장의 흩어진 남미 여행 사진과 동영상을 가지고 계신가요?
이 프로그램은 파일에 저장된 **위치 정보(GPS)**를 분석하여 "국가/도시/날짜" 폴더별로 한 번에 깨끗하게 정리해 주는 데스크탑 유틸리티입니다.

## 🚀 사용 방법 (가장 쉬운 정리법)

1. `PhotoClassifier_실행하기.bat` 파일을 더블 클릭하여 프로그램을 실행합니다.
2. 상단에서 두 가지 폴더를 설정합니다:
   - **Input Folder (원본 사진 위치):** 정리되지 않은 사진/영상들이 모여있는 폴더를 고릅니다.
   - **Output Folder (저장될 위치):** 깨끗하게 정리된 사진들이 담길 "새로운 빈 폴더"를 고릅니다.
3. [고급 옵션]에서 원하는 분류 깊이(Depth)를 조절하세요.
   * `국가/도시/날짜` 형태로 상세하게 나눌지, 단순히 `국가/날짜` 형태로 크게 묶을지 선택할 수 있습니다.
4. **[Run]** 버튼을 누르시면 작업이 시작됩니다!
   * (기본 설정은 `Rename`으로 파일 스토리지 절약을 위해 이동(Move) 처리됩니다. 원본을 유지하고 싶으시면 `Advanced` 대신 탐색기 창 백업 후 진행하시기 바랍니다.)

---

## 📁 결과물은 어떻게 나뉘나요?

분류 작업이 마무리 되면 [출력 폴더(Output)] 안에 다음과 같은 규칙으로 폴더가 생성됩니다.

### 1. 위치 정보(GPS)가 있을 경우
`SouthAmerica / 국가명 / 도시명 / 날짜`
ex) `SouthAmerica / Argentina / Buenos_Aires / 2026.04.10`
* 만약 소도시이거나 반경 내에 등록된 주요 도시가 없다면 `others` 폴더로 자동 분류됩니다.

### 2. 위치정보(GPS)가 없을 경우
`No_GPS / 날짜 / 카메라모델`
ex) `No_GPS / 2026.04.11 / iPhone 14 Pro`
* 위치를 알 수 없는 파일이나 카카오톡 다운로드 사진 등은 이 폴더로 날짜별로 예쁘게 분류됩니다.

### 3. 작업 실패 또는 에러 발생 시
작업이 끝난 후 혹시나 정리에 실패(권한 오류, 메타데이터 파손 등)한 파일이 한 장이라도 있다면, 출력 폴더 최상단에 `error_report.csv` 라는 파일이 생성됩니다. 엇, 파일 몇 개가 어디로 갔지? 싶으실 땐 이 파일을 확인해 보세요!

## 💡 지원 포맷 및 특징
* **지원 확장자:** 사진(.jpg, .heif, .arw 등 RAW 포함), 동영상(.mp4, .mov 등)
* **특징:** 중복된 이미지(크기, 생성일, 부분 해시 일치)는 지능적으로 한 부만 놔두고 정리(`is_duplicate`) 처리하여 여행 디스크 용량을 지켜줍니다.
