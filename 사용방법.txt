[ 남미 여행 사진/영상 자동 지역 분류기 (Photo Classifier) ]

수천 장의 흩어진 남미 여행 사진과 동영상을 가지고 계신가요?
이 프로그램은 파일에 저장된 '위치 정보(GPS)'를 분석하여 '국가/도시/날짜' 폴더별로 한 번에 깨끗하게 정리해 주는 데스크탑 유틸리티입니다.


======================================================
■ 사용 방법 (가장 쉬운 정리법)
======================================================
1. "PhotoClassifier_실행하기.bat" 파일을 더블 클릭하여 프로그램을 실행합니다.
2. 메인 화면에서 두 가지 폴더를 설정합니다:
   - Input Folder (원본 사진 위치): 정리되지 않은 엉망인 사진/영상들이 모여있는 폴더를 고릅니다.
   - Output Folder (저장될 위치): 깨끗하게 정리된 사진들이 담길 '새로운 빈 폴더'를 고릅니다.
3. [고급 옵션]에서 원하는 분류 깊이를 조절할 수 있습니다.
   - GPS가 있는 사진을 '국가/도시/날짜' 형태로 쪼갤지, '국가/날짜'로 크게 묶을지 선택할 수 있습니다.
4. 맨 아래의 [Run] 버튼을 누르시면 작업이 시작됩니다!
   (기본 설정은 Rename으로, 원본 파일이 새로운 폴더로 이동합니다. 혹여나 기존 폴더에 원본을 남겨두길 원하신다면, 원본 폴더를 복사 백업하신 후 진행하시는 것을 권장합니다.)


======================================================
■ 결과물은 어떻게 생성되나요?
======================================================
분류 작업이 마무리 되면 [Output Folder] 안에 다음과 같은 규칙으로 폴더가 생성됩니다.

1. 위치 정보(GPS)가 있을 경우
   SouthAmerica \ 국가명 \ 도시명 \ 날짜
   예) SouthAmerica \ Argentina \ Buenos_Aires \ 2026.04.10
   주의: 만약 소도시이거나 반경 내에 등록된 주요 도시가 없다면 others 폴더로 모입니다.

2. 위치정보(GPS)가 없을 경우
   No_GPS \ 날짜 \ 카메라모델
   예) No_GPS \ 2026.04.11 \ Apple_iPhone 14 Pro
   위치를 알 수 없는 파일이나 카카오톡 저장 사진 등은 이 폴더로 예쁘게 분류됩니다.


======================================================
■ 작업 일지(Log) 확인하는 곳 (DB 폴더)
======================================================
정리 작업이 끝난 후 혹시나 정리에 실패(권한 오류 등)한 파일이 한 장이라도 있다면,
본 프로그램이 설치된 폴더의 [ DB ] 폴더를 열어보세요!
그 안에 다음과 같은 파일들이 기록되어 있습니다:
- DB_report.csv : 정리된 전체 사진의 위치 정보, 촬영일자, 카메라 모델 등의 목록
- error_report.csv : 정리하지 못하고 실패한 사진 명단 및 에러 원인

감사합니다.
