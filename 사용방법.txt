[ Photo Classifier — 미디어 관리 허브 ]

사진/동영상을 자동으로 정리하고, 동영상 해상도를 변환하고,
Live Photo(MP4/MOV)에서 최고 화질의 정지 이미지를 추출하는 통합 데스크탑 유틸리티입니다.

"PhotoClassifier_실행하기.bat" 파일을 더블 클릭하여 프로그램을 실행하세요.


======================================================
■ 도구 1 — 사진/영상 자동 분류기
======================================================
수천 장의 흩어진 사진과 동영상을 파일에 저장된 GPS 위치 정보를 기반으로
'국가 / 도시 / 날짜' 폴더 구조로 자동 정리합니다.

[ 사용 방법 ]
1. 허브 화면에서 "사진/영상 분류기"를 선택합니다.
2. 두 가지 폴더를 설정합니다.
   - 입력 폴더: 정리가 안 된 사진/영상들이 있는 폴더
   - 출력 폴더: 정리된 파일이 저장될 새 폴더
3. [고급 옵션]에서 분류 깊이를 조절합니다.
   - 국가/도시/날짜 (세밀) 또는 국가/날짜 (크게 묶기) 선택 가능
4. [Run] 버튼을 누르면 작업이 시작됩니다.
   (기본 설정은 이동(Move)입니다. 원본을 보존하려면 작업 전 원본 폴더를 백업하세요.)

[ 결과물 폴더 구조 ]
1. GPS 정보가 있는 경우
   국가 \ 도시 \ 날짜
   예) Argentina \ Buenos_Aires \ 2026.04.10

2. GPS 정보가 없는 경우
   No_GPS \ 날짜 \ 카메라모델
   예) No_GPS \ 2026.04.11 \ Apple_iPhone 14 Pro
   (카카오톡 저장 이미지, GPS 없는 스캔 사진 등이 여기 분류됩니다)

[ 작업 로그 확인 (DB 폴더) ]
작업 후 프로그램 폴더의 [DB] 폴더를 열면:
- DB_report.csv    : 전체 파일 목록 (위치, 촬영일, 카메라 모델)
- error_report.csv : 처리 실패 파일 목록 및 원인

[ 오류 대처법 ]
- "GPS 없음" 파일이 너무 많을 때: 사진 앱(Apple Photos, Google Photos 등)에서
  위치 정보를 수동으로 추가한 뒤 다시 내보내세요.
- 도시 인식 실패(others 폴더로 분류): 소도시이거나 등록되지 않은 지역입니다.
  파일을 열어 GPS 좌표를 확인하고 수동으로 원하는 폴더로 이동하세요.
- 권한 오류: 출력 폴더 경로에 한글이나 특수문자가 없는지, 네트워크 드라이브가
  아닌지 확인하세요. 관리자 권한으로 실행해 보세요.


======================================================
■ 도구 2 — 동영상 해상도 변환기
======================================================
4K/2K 동영상을 원하는 해상도(예: 1080p)로 일괄 변환합니다.
NVIDIA / Intel / AMD GPU를 자동 감지하여 하드웨어 가속으로 빠르게 처리합니다.

[ 사용 방법 ]
1. 허브 화면에서 "동영상 해상도 변환기"를 선택합니다.
2. 폴더를 설정합니다.
   - 입력 폴더: 변환할 동영상이 있는 폴더 (하위 폴더 포함)
   - 출력 폴더: 변환된 파일이 저장될 폴더
3. 출력 설정을 선택합니다.
   - 해상도: 1920×1080(풀HD), 1280×720(HD), 3840×2160(4K) 등
   - 코덱: H.264(호환성 우수) 또는 H.265/HEVC(더 작은 파일 크기)
   - 화질: 18=고화질(권장), 23=균형, 28=용량 절약
4. [변환 시작] 버튼을 누릅니다.
   - GPU 가속 사용 가능 여부를 자동으로 감지합니다.
   - 지정 해상도 이하인 파일은 자동으로 건너뜁니다.

[ 참고 ]
- 변환 실패 파일은 출력 폴더의 [_Failed_Conversions] 폴더에 오류 로그가 저장됩니다.
- 오디오는 AAC 256kbps로 재인코딩됩니다.

[ 오류 대처법 ]
- "FFmpeg not found" 오류: assets 폴더에 ffmpeg.exe가 없거나 PATH에 등록되지 않았습니다.
  ffmpeg 공식 사이트에서 다운로드하여 assets 폴더에 넣어주세요.
- GPU 인코딩 실패: 드라이버 문제나 미지원 하드웨어입니다. 자동으로 CPU 인코딩으로
  전환됩니다. CPU 인코딩은 느리지만 동일한 품질로 완료됩니다.
- 변환 후 파일 크기가 원본보다 큰 경우: 화질 값(CRF/CQ)을 더 높게(예: 23)
  설정하면 파일 크기를 줄일 수 있습니다.


======================================================
■ 도구 3 — 라이브 포토 변환기
======================================================
iPhone / Android Live Photo(MP4, MOV)에서 가장 선명한 프레임을 골라
고화질 정지 이미지(JPEG)로 추출합니다.
GPS, 날짜, 카메라 설정 등 EXIF 메타데이터를 완전히 보존합니다.

[ 사용 방법 ]
1. 허브 화면에서 "라이브 포토 변환기"를 선택합니다.
2. 폴더를 설정합니다.
   - 입력 폴더: Live Photo(MP4/MOV) 파일들이 있는 폴더
   - 출력 폴더: 추출된 이미지가 저장될 폴더
3. 출력 설정을 선택합니다.
   - 이미지 포맷: JPEG 권장 (GPS·EXIF 호환성 최우선)
   - JPEG 품질: 95 권장 (Live Photo 원본이 H.264 손실 압축이므로 95로 충분)
   - 프레임 선택: "최선명 프레임" 권장 (Laplacian+Brenner 앙상블 알고리즘)
4. 메타데이터 설정을 확인합니다.
   - EXIF 보전: "보전" 선택 시 exiftool이 필요합니다.
   - exiftool 상태가 상단에 표시됩니다 (초록=정상, 노랑=미탐지).
5. [변환 시작] 버튼을 누릅니다.

[ 지원 카메라 및 EXIF 보존 ]
- iPhone: GPS(위도/경도/고도), 날짜(시간대 포함), 카메라 모델, 렌즈, 조리개, ISO 완전 보존
- Samsung/Sony/Canon/Nikon: EXIF-IFD 내장 방식 — GPS 및 카메라 설정 완전 보존
- DJI 드론: XMP + QuickTime GPS — GPS 좌표 및 촬영 정보 보존
- GoPro: QuickTime GPS 원자(atom) — GPS 좌표 보존
- 구형 Android: QuickTime 타임스탬프 — 날짜/시간 보존

[ 오류 대처법 ]
- "⚠️ exiftool 미탐지": EXIF 보전 기능을 사용할 수 없습니다.
  assets 폴더에 exiftool.exe와 exiftool_files 폴더가 있는지 확인하세요.
  없으면 exiftool 공식 사이트(https://exiftool.org)에서 Windows 빌드를 다운로드하여
  assets 폴더에 복사하세요.
- 변환 후 GPS가 없는 경우: 원본 영상에 GPS 정보가 없는 것입니다.
  원본 파일을 exiftool로 직접 확인해 보세요: exiftool 파일명.mp4
- 이미지가 흐리게 추출되는 경우: 프레임 선택을 "최선명 프레임"으로 변경하세요.


======================================================
■ 공통 오류 대처법
======================================================
- 프로그램이 실행되지 않을 때:
  "PhotoClassifier_실행하기.bat"을 마우스 오른쪽 클릭 → "관리자 권한으로 실행"

- 처리 중 프로그램이 멈춘 경우:
  [취소] 버튼을 누르고 잠시 기다리세요. 현재 처리 중인 파일이 완료된 후 중단됩니다.

- 폴더 경로 오류:
  폴더 경로에 특수문자나 매우 긴 경로(260자 초과)가 없는지 확인하세요.

- 여전히 해결이 안 되는 경우:
  개발자에게 문의해 주세요.
